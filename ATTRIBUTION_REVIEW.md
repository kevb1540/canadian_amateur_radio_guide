# Attribution and accuracy review

The app now presents the full recorded source titles, authors/publishers where known, and an explicit version URL for each source. The ISED question bank is attributed to its recorded source ZIP and July 15, 2025 edition.

**Limit:** Existing metadata is not evidence that each referenced page or each of the 984 questions was newly compared with the current original publication. Source verification labels explicitly reflect this. Some reference titles are descriptive rather than independently confirmed full official publication titles; these require further manual verification. Independently written or paraphrased explanations must not be represented as verbatim reproductions.

Before release: verify each original URL, confirm each full official document title and author, compare every reproduced item to the original edition, check the question-bank checksum and answer key against the official download, and review current regulatory requirements. Record verification dates and outcomes per source.
