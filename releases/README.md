Requires Android 8.0 or newer. Open the APK and choose **Update** over the
existing app to keep current profiles and progress. Version code is 242;
package and signing identity match the previous release.

**Delete User** is available before login after selecting a user, and in
Profile settings. No password is required. A separate confirmation identifies
the selected user; Cancel and Android Back keep the profile. Confirmation
removes only that local profile and its work and returns to login. Other users
and exported backups are kept. A complete User backup can restore the profile.

colours, chapter achievements, on-air terms, profiles, avatars, .carprog backups,
and Kevin's built-in recovery service address.
